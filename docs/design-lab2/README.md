# ЛР2 — анализ рентабельности продукции

Готовая команда проверки контрактов: [TESTING.md](TESTING.md).

Тема: программное средство анализа рентабельности продукции с интеграцией данных производственного и финансового учета.

По методическим указаниям ЛР2 не требует реализации рабочего приложения. Требуется техническое проектирование:
- структуры БД сервисов;
- GraphQL schema;
- gRPC/protobuf-контракты;
- Kafka-события и payload;
- сценарии взаимодействия.

В этот ZIP вынесены именно те части работы, которые естественно оформляются как код/контракты:

- `graphql/schema.graphql` — внешняя GraphQL schema;
- `proto/profitability.proto` — gRPC-контракты;
- `kafka/event-envelope.schema.json` — общий формат Kafka-события;
- `kafka/examples/*.json` — примеры событий;
- `sql/*.sql` — DDL таблиц по принципу Database per Service.

Полноценная реализация микросервисов в ЛР2 не требуется.
